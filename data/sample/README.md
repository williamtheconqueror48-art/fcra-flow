# data/sample/

Illustrative sample filings used by the scaffold UI until bulk FCRA ingestion
ships.

- `sample_fcra.json` — 24 illustrative Form FC-4-style rows (FY 2021-22 to
  2023-24). Registration numbers are masked (`12XXX1234X` pattern). Values are
  illustrative; any resemblance to real filings is coincidental.
- `../flags.json` — mechanical flag definitions (shared with the app).

Nothing in this directory is a real disclosure record.
